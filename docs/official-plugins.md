# Official ChatGPT Plugins and OpenAI GitHub Source Packages

A curated directory of installable ChatGPT store plugins and inspectable source packages published in the official `openai/plugins` repository.

## Overview

OpenAI Dots connects to third-party web services primarily through the ChatGPT plugin architecture. This catalog indexes:
1. Public Directory Listings: Installable directly within the ChatGPT Desktop and Web interfaces (`chatgpt.com/plugins/...`).
2. GitHub Source Packages: Source code folders under `openai/plugins/tree/main/plugins/` containing plugin manifests, tool schemas, and MCP configurations.
