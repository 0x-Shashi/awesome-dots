# Personal Admin Dots

Autonomous agents and workflows configured for daily logistics, family schedules, subscription hygiene, travel itineraries, and personal chores.

## Catalog

* [Executive Morning Standup Briefing](https://dotsguide.com/get-started) - Synthesizes personal commitments, urgent communications, weather forecasts, and task priorities into a morning summary.
* [Unified Travel Itinerary Builder](https://help.openai.com/en/articles/20001530-getting-started-with-your-dot) - Pulls airline confirmations, hotel reservations, and rental car bookings into a single, time-indexed trip document.
* [Household Maintenance Scheduler](https://learn.chatgpt.com/docs/dots/tasks-and-memory#recurring-tasks) - Tracks periodic home maintenance tasks, vehicle inspections, and service intervals, creating reminders ahead of due dates.
* [Warranty and Return Window Tracker](https://help.openai.com/en/articles/20001529-dots-privacy-security-and-safety-faqs) - Catalogs purchase invoices, tracks return deadlines, and alerts the user prior to return window expiration.
* [Personal Subscription Renewal Alert](https://dotsguide.com/pricing) - Monitors personal credit card receipt notifications for recurring digital services, flagging annual renewal dates.
