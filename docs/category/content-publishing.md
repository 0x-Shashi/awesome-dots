# Content and Publishing Dots

Autonomous agents and workflows configured for long-form drafting, media repurposing, changelog authoring, and publishing pipeline management.

## Catalog

* [Interview Transcript Repurposer](https://learn.chatgpt.com/docs/dots#work-with-your-dot) - Transforms raw interview audio transcripts into structured technical articles, newsletter summaries, and presentation slide outlines.
* [Automated Release Changelog Generator](https://learn.chatgpt.com/docs/dots#work-with-your-dot) - Pulls merged pull requests, tags, and milestone summaries from Git repositories and drafts user-facing release notes.
* [Multi-Channel Social Copy Drafter](https://dotsguide.com/get-started) - Formats core marketing announcements into platform-tailored drafts for LinkedIn, X, and internal community portals.
* [Media Asset Cataloger](https://learn.chatgpt.com/docs/dots#give-it-a-responsibility) - Ingests visual and audio assets, attaches descriptive metadata tags, and logs entries into team publishing schedules.
* [Documentation Drift Inspector](https://chenrui333.github.io/codex-docs/) - Compares production feature updates against public user documentation to identify obsolete setup steps.
