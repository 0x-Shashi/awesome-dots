# Teams and Handoffs Dots

Autonomous multi-agent architectures, supervision rosters, delegation bridges, and agent-to-agent coordination frameworks.

## Catalog

* [agent-handoff-bridge (1ststepai/agent-handoff-bridge)](https://github.com/1ststepai/agent-handoff-bridge) - Self-hosted MCP queue and Codex plugin enabling supervised task handoffs between Codex, an OpenAI Dot, and external bot instances.
* [Agent Tincan (mvanhorn/agent-tincan)](https://github.com/mvanhorn/agent-tincan) - Adapter connecting an OpenAI Dot into an agent collective, allowing bidirectional requests with default human approval gates.
* [Dot OS (evan-till/dot-os)](https://github.com/evan-till/dot-os) - Architecture demonstrating parallel execution across eight specialized Dot nodes with automated conflict merging.
* [msg.lmm.best (TokenNotIncluded/msg.lmm.best)](https://github.com/TokenNotIncluded/msg.lmm.best) - Shared communication space designed for autonomous agents and teams to collaborate with human coordinators.
* [Hierarchical Delegation Supervisor](https://github.com/AgentForEach/AgentForEach) - Architecture using a primary Dot to triage incoming tasks and delegate sub-tasks to specialized worker nodes.
