# Inbox and Calendar Dots

Autonomous agents and workflows configured for email prioritization, schedule hygiene, meeting briefings, and calendar defense.

## Catalog

* [Safe Email Triage Strategy (dragapp.com)](https://www.dragapp.com/blog/openai-dots/) - Guide and rule set for allowing a Dot to inspect inbox traffic and generate draft responses without autonomous send permissions.
* [Morning Calendar Defense Briefing](https://learn.chatgpt.com/docs/dots/tasks-and-memory#recurring-tasks) - Recurring morning task that inspects the day agenda, identifies scheduling conflicts, and creates private focus blocks.
* [Meeting Preparation Context Compiler](https://learn.chatgpt.com/docs/dots#work-with-your-dot) - Pulls related correspondence, past decision notes, and attendee context ahead of scheduled meetings.
* [Action Item Follow-up Extractor](https://learn.chatgpt.com/docs/dots/tasks-and-memory) - Scans meeting transcripts or notes, identifies commitments, and prepares draft follow-up emails for review.
* [VIP Communication Filter](https://dotsguide.com/get-started) - Filters high-priority sender messages, alerting the user via mobile push while queuing routine newsletters.
