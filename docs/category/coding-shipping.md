# Coding and Shipping Dots

Autonomous agents and workflows configured for software engineering, continuous delivery, pull request management, and environment maintenance.

## Catalog

* [dotlink (abird-ai/dotlink)](https://github.com/abird-ai/dotlink) - Local workspace bridge via secure MCP tunnel, granting bounded access to run Git commands, execute test suites, and inspect builds.
* [codex-docs Mirror (chenrui333/codex-docs)](https://github.com/chenrui333/codex-docs) - Git tracked documentation mirror capturing updates and changes across official OpenAI agent docs.
* [Codex Docs Skill (mehmetbaykar/codex-docs-skill)](https://github.com/mehmetbaykar/codex-docs-skill) - Agent context retrieval skill enabling Dots to look up and reference the latest Codex documentation.
* [Automated Bug Reproduction Agent](https://learn.chatgpt.com/docs/dots#work-with-your-dot) - Official workflow that parses bug reports from customer feedback, finds the source code path, and drafts a reproduction script.
* [PR Review and Verification Assistant](https://learn.chatgpt.com/docs/dots#work-with-your-dot) - Prepares branch diff summaries, checks for regression risks, and prepares validation notes for human sign-off.
* [Release Tag Monitor](https://github.com/openai/plugins) - Plugin automation that monitors release tags across dependencies and flags breaking API changes.
