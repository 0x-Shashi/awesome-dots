# Contribution Guidelines

Contributions to this curated catalog of OpenAI Dots resources, architectures, and workflows are warmly encouraged.

## Review Standards

* Every entry must point to functional tools, documented official capabilities, or verifiable case studies.
* Avoid speculative listings or unverified rumors.
* State security permissions clearly for any connector or desktop extension.
* Maintain clean formatting without icons, emojis, or non-standard punctuation.
* Use English across all documentation and annotations.

## Submitting New Entries

1. Fork this repository and create a descriptive feature branch.
2. Add your resource to the relevant section within the main README file, adhering to alphabetical ordering where applicable.
3. If introducing an integration or connector, ensure it follows the format documented in integrations/connector_blueprint.md.
4. Open a pull request providing a concise summary of the contribution and reference links.
